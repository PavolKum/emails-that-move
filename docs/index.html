What's in the kit

Four tricks that survive Outlook

Outlook has two rendering engines and strips most of what the web takes for granted. These are the tricks that still get through.

Charts that draw themselves

Lines draw on, donuts sweep, bars grow. Frame 1 is the finished chart, so an Outlook that won't animate still shows the numbers. Each GIF plays three times, matching the Microsoft 365 cap.

Click the chart to replay it.

Vector graphics in classic Outlook

Classic Outlook renders HTML with Word, which ignores most CSS. It still draws VML, Microsoft's vector format from 1998, so donuts and line charts stay sharp there too.

Shown: Word's own render of the Roast Report email.

Scenes that breathe

A night tower that never quite sits still: one GIF of 24 frames, built so the last frame flows into the first. A window going dark passes through an afterglow frame, so the flicker stays soft.

Frame 1 is the tower at rest, which is what a non-animating Outlook shows.
